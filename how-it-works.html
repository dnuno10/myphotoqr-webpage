Quick answers

Do guests need to install an app?

No. MyPhotoQR works from the browser on mobile, tablet and desktop.

Can I protect the album with a code?

Yes. You can use access protection so only people with the code can view or upload.

Can I review uploads before they appear?

Yes. Use moderation to approve, hide, feature or auto-approve content.

What happens if internet is slow?

Guests can try again when the connection improves. For best results, place the QR near areas with strong mobile data or Wi‑Fi.
